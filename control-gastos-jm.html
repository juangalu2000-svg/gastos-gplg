🗑️ ¿Borrar todos los datos?

Se eliminarán todos los movimientos, categorías y reglas aprendidas. Esta acción no se puede deshacer.

💾 Cómo usar el backup

Exportar → Pulsa "Exportar JSON". Se descargará un archivo cgj_backup_FECHA.json. Guárdalo en tu Dropbox.

Importar ← Abre el archivo desde Dropbox, luego pulsa "Importar JSON" y selecciónalo. Todos tus datos se restaurarán.

¿Cuándo hacerlo? Cada vez que termines de categorizar los movimientos nuevos. Si limpias el caché del navegador perderás los datos locales, pero el JSON en Dropbox siempre tendrá la última copia.
